Dockline — Design System

Color

Palette & roles

One token set drives both modes. Only --bg, --surface, --ink and --accent shift value between themes — every component references the variable, never a raw hex.

Typography

Type scale

Three families, three jobs: Fraunces for display headlines, Inter for reading text and UI labels, IBM Plex Mono for data — SKUs, stats, eyebrows, timestamps.

Motion

Animation specs

Everything runs on one easing curve — cubic-bezier(.22,.9,.32,1) — so the page feels like one mechanism, not several. All motion respects prefers-reduced-motion.

Hero rise-in
Each hero element fades up 16px on page load, staggered 120ms apart (eyebrow → headline → lede → CTAs → note).
